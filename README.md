# Hex AutoDraw — Native Android Project

Hex AutoDraw is a native Android application built with Kotlin and Jetpack Compose.
It dispatches real touch gestures onto WePlay's "Guess My Drawing" canvas via Android's AccessibilityService.

### Quick Setup:
1. Open this directory in Android Studio.
2. Connect your phone with USB Debugging enabled.
3. Click Run (Play) or run './gradlew installDebug'.
4. Grant Accessibility Service & Display Over Other Apps.
5. In Hex AutoDraw, tap 'Crop Drawing Area', open WePlay, align the 4 handles to the canvas, and tap Start Drawing!
